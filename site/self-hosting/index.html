Self-hosting

One compose file runs the app, the worker, the SMTP ingress, Postgres and Valkey. You bring a provider account and an S3-compatible bucket.

Run it

git clone https://github.com/joeyyax/pouch
cd pouch
cp .env.example .env     # fill it in
docker compose -f docker-compose.self-host.yml up -d

The app listens on APP_PORT (3100 by default). Put your own TLS terminator in front of it and set APP_URL to the public address. Links in mail, webhook payloads and unsubscribe URLs all come from it.

There's no published image yet, so the first up builds from source.

What you have to set

VariableWhat it's for
APP_URLEvery link Pouch mails or signs.
ENCRYPTION_KEYMessage bodies and provider credentials at rest. Losing it loses both.
BETTER_AUTH_SECRETSessions and list confirmation tokens.
POSTGRES_PASSWORDThe bundled database. Ignored when DATABASE_URL is set.
STORAGE_*The bucket for bodies and attachments. Any S3-compatible store.
ADMIN_EMAIL, ADMIN_PASSWORDThe first account. Public sign-up is off.
SEED_PROVIDER_CREDENTIALS, SEED_DOMAINThe provider and domain the install starts with.

The app, worker and SMTP ingress check their configuration at boot. They refuse to start without a variable they need, or with the development secrets .env.example ships with, and name each one. lib/config.ts lists every variable.

Bundled or external Postgres and Valkey

Bundled is the default. To use a managed database or cache, set DATABASE_URL and REDIS_URL and start only the app services:

docker compose -f docker-compose.self-host.yml \
  up -d --no-deps mail mail-worker mail-smtp

SMTP

Port 587 with STARTTLS is published. It needs a certificate for SMTP_TLS_HOST in SMTP_CERT_DIR (./certs), as certificate.crt and privatekey.key, readable by uid 1001. Without one, 587 refuses every send rather than accept a key in the clear.

A host that can open 465 turns on implicit TLS with SMTP_IMPLICIT_TLS_PORT.

Settings file

Settings from the admin screens can be pinned in pouch.yml. Copy pouch.example.yml, uncomment what to pin and mount it at /app/pouch.yml on all three services. Environment variables still win over the file, and secrets stay in the environment.

Search

Dashboard search runs on Postgres. For typo-tolerant matches, point MEILISEARCH_URL at a Meilisearch you run.
