Authenticate with `Authorization: Bearer <key>`. JSON in, JSON out. Errors, pagination and the rest are in [API conventions](/conventions/).

To try a request from a page here, open the server URL in its playground and enter your install's `APP_URL`. Every install has its own, so there's no default.

The same document is at `/openapi.json` on every install, with that install's URL filled in.
