title: Pouch docs

---

Every install has its own URL. Examples here use `https://pouch.example.com`; swap in your install's `APP_URL`.

```bash
curl https://pouch.example.com/v1/emails \
  -H "Authorization: Bearer $POUCH_KEY" \
  -H "Content-Type: application/json" \
  -d '{"from": "Ada <ada@example.com>", "to": "sam@example.net", "subject": "Hello", "text": "It works."}'
```

The TypeScript client is `@joeyyax/pouch` on npm. It needs the same `baseUrl`.
